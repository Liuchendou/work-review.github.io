周度复盘

复盘一周的记录。把这一周的每日记录和情绪记录过一遍，再写。

行动写不具体？用「4W1H + 预算」拆一下

要让行动变得具体可实施，不妨试着将它们整理成「4W1H + 预算」的形式。
When（何时）· Where（何地）· Who（和谁）· What（做什么）· How（怎么做）· How much（花费多少）
何时：请明确具体行动的日期。何地：请尽量细化到具体的地点和区域。和谁：请写出具体的姓名或对象。做什么、怎么做：要具体到你能立刻开始行动的程度。

这一周想不到写什么？用「抽象化项目一览」往里看一层

越靠下，抽象程度越高。枝叶是这周直接看得见的，先写这些；根系要慢慢来。

枝叶可见期
① 自己的状态 —— 本周你的头脑、内心和身体状态怎么样？
② 内心最在意的事 —— 当下你最在意的事有哪些？
③ 重要人物 —— 对你来说，生活中的重要人物是谁？
树干可见期
④ 兴趣所在 —— 你最近在关注什么？
⑤ 优势和特长 —— 你的优势和特长是什么？
⑥ 思维模式和行为模式 —— 你惯常的思维模式或行为模式有哪些？
根系可见期
⑦ 形成思维模式和行为模式的信念和固有观念 —— 促使你形成这些模式的根源是什么？
⑧ 想法和愿望 —— 你真正渴望的是什么？想要成为什么样的人？

GitHub 同步

手机和电脑各填一次同一个令牌，两端就共用一份记录。令牌只存在这台设备的浏览器里，不会写进这个网页文件。

令牌怎么拿？只勾 gist 一项权限

GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)。只勾 gist 这一项（其余都不要勾），有效期按你的习惯选。生成后复制那串 ghp_ 开头的字符，粘到上面的框里。两台设备粘同一个就行 —— 保存后我会自己去找（找不到就新建）一个标题带「复盘工作台」的私有 Gist，数据存在那儿。
